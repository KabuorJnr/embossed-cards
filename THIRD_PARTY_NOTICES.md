# Third party notices

Embossed has no third party scripts, trackers or SDKs at runtime. The only third party material it ships is fonts, all under the SIL Open Font Licence 1.1, installed through the Fontsource packages and served from this site.

| Font | Use | Licence |
| --- | --- | --- |
| Bodoni Moda | Wordmark, headings, classic handwriting option | SIL OFL 1.1 |
| Hanken Grotesk | Interface text | SIL OFL 1.1 |
| Caveat | Casual handwriting | SIL OFL 1.1 |
| Pinyon Script | Script handwriting | SIL OFL 1.1 |
| Marcellus | Words on the cover | SIL OFL 1.1 |

Full licence text ships with each package in `node_modules/@fontsource/*/LICENSE`.

All card artwork, icons and images are original, drawn in code for Embossed.

Build tools (Vite, TypeScript, Vitest) are used only during development and are not shipped to visitors.
